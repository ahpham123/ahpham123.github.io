# ahpham123.github.io

My portfolio site. It renders as a small cottage garden you can look around in, with rock labels on the lawn that open each section. There is a day/night toggle in the navbar if you want to see the fireflies.

Live at [ahpham123.github.io](https://ahpham123.github.io).

## Built with

- Next.js (static export) and TypeScript
- Tailwind CSS
- Motion for UI animation
- three.js with React Three Fiber for the garden scene

## Running locally

```bash
npm install
npm run dev
```

Node 22 is expected, see `.node-version`.

## Deploying

Pushing to `main` runs a GitHub Actions workflow that builds the site and publishes it to GitHub Pages.
